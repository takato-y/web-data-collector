## 1. 背景・目的

### 1.1 想定する業務

想定する業務は、架空の小売事業者の商品担当者が行う「仕入先・競合の Web ショップの価格と在庫の確認」です。対象サイトはすべて架空で、本リポジトリでは手元のパソコン上で動く架空のデモショップ（以下「デモショップ」）を対象にします。実在のサイトからは収集しません。

### 1.2 これまでの課題

| 課題 | 内容 |
|---|---|
| 確認に時間がかかる | 担当者が毎朝、数十件の商品ページを 1 件ずつ開き、価格と在庫を Excel に書き写している |
| 変化を見落とす | 値下げや在庫切れは前日の記録と目で見比べて探すため、見落としや気付きの遅れが起きる |
| 記録が残らない | 書き写した表を上書きしてしまい、価格がいつ変わったかを後から追えない |
| 共有が遅い | 変化に気付いても、関係者への連絡は担当者が手でチャットに書き込んでいる |

### 1.3 目的

- 価格・在庫の確認作業を自動化し、担当者は「変化があった商品」だけを確認すればよい状態にする
- 収集した値を履歴として残し、価格の推移を後から追えるようにする
- 変化をチャットツールへ自動で知らせる
- 収集にあたって対象サイトに負担をかけず、利用規約と robots.txt（サイトが自動収集の可否を示すファイル）の取り決めを守る

## 2. 機能要件

| ID | 要件 | 優先度 |
|---|---|---|
| REQ-001 | 対象サイトの商品一覧（複数ページ）から、商品ID・商品名・価格・詳細ページの URL を収集する | 必須 |
| REQ-002 | 商品詳細ページから在庫状況とカテゴリを取得する | 必須 |
| REQ-003 | JavaScript で後から描画されるページからも商品を収集できる（追加の部品が導入済みの場合だけ） | 任意 |
| REQ-004 | 収集前に robots.txt を確認し、収集が禁止されたページは取得しない | 必須 |
| REQ-005 | ページの取得ごとに間隔を空け、対象サイトへの負荷を抑える。robots.txt に待ち時間（Crawl-delay）の指定があれば、長い方に従う | 必須 |
| REQ-006 | 通信の失敗・一時的な混雑の応答には、間隔を広げながら決まった回数だけ再試行し、応答のない通信は一定時間で打ち切る | 必須 |
| REQ-007 | 収集した値を実行ごとに履歴として保存する | 必須 |
| REQ-008 | 前回の収集との差から、値下げ・値上げ・在庫切れ・再入荷・新商品・掲載終了を検出する | 必須 |
| REQ-009 | 変更一覧（種類ごとに色分け）・最新一覧・価格推移グラフを含む Excel レポートを出力する | 必須 |
| REQ-010 | 検出した変更をチャットツールの Webhook（決まった URL に送るだけで投稿できる仕組み）へ通知する。送信に失敗した変更は次回に再送する | 必須 |
| REQ-011 | 収集対象・抽出位置（CSS セレクタ）・間隔・通知先などを設定ファイル（YAML）で変更できる | 必須 |
| REQ-012 | cron（Linux）・タスクスケジューラ（Windows）から 1 コマンドで定期実行できる | 必須 |
| REQ-013 | Web 由来の文字列によって、Excel で数式が実行されたり、チャットで全員宛ての呼び出しが起きたりしないようにする | 必須 |

## 3. 非機能要件

| ID | 区分 | 内容 |
|---|---|---|
| NFR-001 | 対象サイトへの負荷 | 同じサイトへの取得は既定で 1 秒に 1 回以下とする。1 回の実行で取得するページ数に上限を設け、ページ送りが終わらない場合も止まる |
| NFR-002 | 法令・規約の順守 | 収集前に対象サイトの利用規約と robots.txt を利用者が確認することを手順に含める。ツールは robots.txt で禁止されたページを取得しない。robots.txt が一時的に取得できない場合は、そのサイト全体の収集を見送る。ログイン後のページ・個人情報は収集対象にしない |
| NFR-003 | 名乗り | 通信時の User-Agent（アクセス元を示す名乗り）にツール名と連絡先ページの URL を入れ、対象サイトの管理者が問い合わせられるようにする |
| NFR-004 | 障害時の扱い | 一部のページが取得できなかった実行では、「掲載終了」の判定を行わない（取得できなかった商品を掲載終了と誤報しないため）。通知の送信に失敗しても収集結果は保存し、未送信の変更は次回に送る |
| NFR-005 | 秘匿情報 | Webhook の URL は環境変数で渡し、設定ファイル・リポジトリ・ログに書かない |
| NFR-006 | 記録 | 実行ごとに開始・終了・取得ページ数・取得件数・エラー件数を履歴に残し、ログファイルにも出力する |
| NFR-007 | 実行時間 | デモショップ（商品 13 件・既定の 1 秒間隔）で 1 回の収集が 1 分以内に終わる |

## 4. 対象外

- 実在の Web サイトからの収集（本リポジトリでは架空のデモショップのみを対象とする）
- ログインが必要なページ、CAPTCHA（ロボットよけの確認画面）の回避、アクセス制限の回避
- 収集した値の社外への再配布・公開
- 画像の収集、商品説明文の全文保存
- 通知先チャットツール（Slack・Teams・Discord）の実サービスへの送信確認（形式は各サービスの公開仕様に合わせるが、実際の送信は手元の受信用モックで確認する）

## 5. 用語

| 用語 | 意味 |
|---|---|
| robots.txt | サイトの管理者が、自動収集プログラムに対して取得してよい範囲を示すファイル |
| Crawl-delay | robots.txt に書かれる、取得の間隔（秒）の希望 |
| User-Agent | 通信時に送る「アクセス元の名乗り」 |
| CSS セレクタ | ページの中のどの部分を取り出すかを指定する書き方 |
| Webhook | 決まった URL にデータを送るだけで、チャットに投稿できる仕組み |
| スナップショット | ある実行時点での商品ごとの価格・在庫の記録 |
