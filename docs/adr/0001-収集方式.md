## 背景

対象ページの多くは、サーバーから届いた HTML にそのまま商品が書かれている。一方で一部のページは、JavaScript が後から商品を描画するため、HTML を取得しただけでは中身が無い。

## 決定

- 通常のページは requests（HTTP 取得）と BeautifulSoup（HTML 解析）で取得・解析する
- JavaScript で描画されるページだけ、設定で `type: js` と指定し、Playwright（ブラウザを自動操作する部品）で描画後の HTML を取り出す。解析は通常のページと同じ処理を使う
- Playwright は任意の依存とし、入っていない環境では該当の対象だけを「見送り」として記録し、ほかの対象の収集は続ける

## 理由

- ブラウザを起動しない方が速く、対象サイトに画像や広告などの余計な読み込みを発生させない
- ブラウザ操作は導入の手間が大きい（ブラウザ本体の取得が必要）。必要な利用者だけが入れればよい
- 解析を共通にすることで、セレクタの書き方を 1 通りにできる

## 影響

- `type: js` の対象でも robots.txt の確認と取得間隔の制御は行う（ブラウザが読み込む付随ファイルは制御の対象外のため、JavaScript ページは必要最小限に限る）
