## 1. 方針

- 収集部（TypeScript）は node:test、分析部（Python）は pytest で試験する
- 収集部の試験は、試験の中で 127.0.0.1 に小さな Web サーバーを立てて行う。実在のサイトには接続しない
- 分析部の試験は、収集部と同じ書き方で履歴DB にデータを入れて行う（`tests/db_seed.py`）。受け渡し口が履歴DB だけなので、収集部を動かさずに試験できる
- 両方をつないだ確認は、架空のデモショップと受信用モックを使う通し試験（`scripts/e2e.sh`）で行う
- 「実施結果」には、実際に実行した結果だけを書く。実行していないものは「未実施」と書く
